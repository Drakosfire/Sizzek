## Findings from Analysis

### Architecture Discovery:
- **Centralized configuration**: All MCP servers use shared `./config/.env.sizzek` file
- **Individual .env files** are overriding the shared configuration (this is the problem)
- **MCP servers already support mcp-data**: Most have sophisticated storage implementations

### Major Issues Discovered:
1. **LibreChat docker-compose.yml overriding shared config**: Hardcoded environment variables in LibreChat/docker-compose.yml:
   - `CONTACTS_DATA_DIR=/app/mcp-data/twilio-sms`
   - `TASKS_FILE_PATH=/app/mcp-data/scheduled-tasks/tasks.json`
   - `MCP_MOVIES_DATA_DIR=/app/mcp-data/movies`
   - `GOOGLE_CALENDAR_MCP_TOKEN_PATH=/app/mcp-data/google-calendar/tokens.json`
   - `GMAIL_OAUTH_PATH=/app/mcp-data/gmail/gcp-oauth.keys.json`
   - `GMAIL_CREDENTIALS_PATH=/app/mcp-data/gmail/credentials.json`
2. **Individual .env files overriding shared config**: Each server has its own `.env` file that overrides the centralized settings
3. **Host paths in shared config**: 
   - `MCP_WEB_UI_CSS_PATH=~/projects/Sizzek/mcp-servers/grocery-list/static` (host path)
4. **Wrong .env file in grocery-list**: Contains todoodles configuration, not grocery-list
5. **Mixed naming conventions**: Shared config uses `MONGO_URI`, some servers expect `MONGO_URI`
6. **Host paths in individual .env files**: 
   - `twilio-sms`: `CONTACTS_DATA_DIR=/app/mcp-data/twilio-sms` (Docker path)
   - `movies`: `MCP_MOVIES_DATA_DIR=/media/drakosfire/Projects/Sizzek/memory_files` (host path)

## Migration Pattern (from grocery-list success)
1. Add `"mcp-data": "^1.0.1"` to package.json dependencies
2. Import `StorageFactory` from 'mcp-data'
3. Replace file storage with `StorageFactory.createUserStorage()`
4. Use shared environment variables from `.env.sizzek`
5. Test in Docker container
